# Friendship Test - Vercel

Cartella pronta per il deploy su Vercel.

## File da pubblicare

- `index.html`
- `style.css`
- `script.js`
- `vercel.json`

## Prima di pubblicare

In Supabase devi aver eseguito il contenuto di `supabase-setup.sql` dalla cartella originale del progetto.

## Deploy veloce

1. Vai su https://vercel.com/
2. Crea un nuovo progetto.
3. Carica questa cartella con drag and drop, oppure mettila in una repo GitHub.
4. Vercel ti dara un link pubblico.
5. Usa quel link per generare il QR code.
